# 一起成长 · 独立 macOS 交付件（构建号 313）

这是一个**可以直接双击试用**的 macOS 交付件：原生客户端 App「一起成长.app」＋全虚构的本地演示后台启动器（默认一天故事、真模型抽取、十八渠道三条入口）。

## 三、十八渠道演示（18 条消息 → 8 件事）

**看什么**：双击 `一起成长·十八渠道演示.command` 后，App 连到一个**离线回放**的十八渠道快照（不调模型、不联网），两个虚构孩子各一张清单页：

- **数据日期固定在 2026-11-04**：打开时 App 首页显示的是真实「今天」；请点周条上的「**11月4日 · 周三**」，就能看到这份快照的完整 8 件事。快照数据日期固定，不随打开时间变化，也不会有「今天漂移」。
- 示例甲：今天 3 张卡（英语《每日练习》并明天带来、数学《每日练习》第26页、朗读《风经过小巷》）；另有 1 张**已取消待核**（美术：带落叶事项已取消，默认收在「日期未定」页）。
- 示例乙：今天 2 张卡（语文《识字小卡》、数学《计算小卡》）；明天带物 2 件收在「**即将/待补：11-05 明天带一盒彩笔；11-05 带一张一寸证件照交班主任**」一行里，点开可看详情。

## 四、App 与后台是什么关系

- **App 是客户端**：原生 SwiftUI/WebKit 外壳，启动时读自己的配置（`desktop.json` 里的 `service_origin`），探测该地址确实是「一起成长」网页后打开工作台。
- **后台是完整的家庭服务**：由 REPO 的 `demo.py` 以「全虚构数据」启动（`python3 -B demo.py --port 8766`），网页 UI 与原生 UI 读同一份 `/api/day`；十八渠道入口则回放快照数据库。
- **本交付件不含内置 Python 运行时**：构建机没有 `FAMILY_MAC_MATERIALS` / `FAMILY_MAC_WHEELS`（REPO `packaging/macos/build.sh` 只在两者同时设置时才运行 `build_bundle.py`，把 CPython 运行时和 wheels 打进 App）。所以这里构建出的是**「连接入口」客户端 App**，必须配一个后台。
- **不会覆盖家长真实 App 配置**：启动器把演示配置写到交付目录的 `.support/desktop.json`（十八渠道是 `.support-十八渠道/`），再用 `open -n --env "FAMILY_DESKTOP_SUPPORT_DIR=…"` 交给 App（REPO `packaging/macos/Sources/main.swift:17` 支持该环境变量；配置文件名见 `main.swift:53`）。默认的 `~/Library/Application Support/local.yiqichengzhang.desktop/desktop.json` 全程不读不写。

### 在真实家庭环境换成真实后台

App 只是客户端；换成真实后台只要改它读的 `desktop.json` 里的 `service_origin`：

```json
{"service_origin": "http://127.0.0.1:8765"}
```

- 默认配置文件：`~/Library/Application Support/local.yiqichengzhang.desktop/desktop.json`（改这个就是改真实配置；演示启动器**不会**碰它）；
- 或临时用另一个配置目录：`FAMILY_DESKTOP_SUPPORT_DIR=/path/to/dir open -n 一起成长.app`；
- `service_origin` 指向真实一起成长后台（自带后台的完整包默认就是本机 8765），App 探测到 `app.bundle.js` 后进入工作台。

- `codesign --verify --deep --strict` 通过、`codesign -dv` 显示 ad-hoc 签名有效；

- 十八渠道数据在 headless 浏览器里按 360/1440 渲染并断言无截断/溢出/写请求。

真正打开窗口的那一次，留给用户双击（或交接时在允许可见窗口的机器上做）。
