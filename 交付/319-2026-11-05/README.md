# 交付 319（2026-11-05）· 看得出跨几天

代码在 `main` 的 `5e3c579`。这一版在 318 的「一列卡片 + 点开浮层」上补了**跨天信息**：清单里一眼看出这件事横跨几天、还剩几天；详情里看得到「布置 → 今天 → 截止」的时间线。仍是体验版，全虚构数据。

## 一眼看变化

1. **卡片一行「跨 N 天」+ 逐日圆点**：只有 `span >= 2`（跨天）的事项才画标尺；单日事项不画（演示里「语文：完成《识字小卡》练习」就是单日无标尺对照）。
2. **剩余文案按天算**：`还剩 N 天` / `明天截止` / `今天截止` / `已过期 N 天`，不编时分、不编日期。
3. **详情「时间线」**：布置日 → 今天 → 截止日三个节点，中间写「还有 N 天」；没有发布日期的任务只显示剩余/过期、不画标尺；没有截止日期写「未写截止」；已取消的事项不显示标尺。
