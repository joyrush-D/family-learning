## 产品怎么用

始终选择一个孩子，所有跟踪事项按科目聚类，以平铺列表处理：**今天做什么 → 查看资料/按需打印 → 提交作答与反馈 → 留错题和订正 → 后续回看。** 老师群里没有的口头作业，可以由孩子或家长补录进同一清单。

Agent负责收集、理解与归类明确消息，只把具体疑点交给家长；发布时间、完成日、交回/检查日分别表达，老师原话和原件可追溯。孩子表现与学校要求分别保留，AI判断不等于已掌握。
