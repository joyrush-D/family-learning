# 一起成长 · Family Agent

把已授权学校信息和孩子补录整理成一个孩子每天清楚的课程、作业与事务，并沿原作业跟进反馈、错题、知识点和复习。

**唯一产品文档：[PRD.md](PRD.md)。** 产品目标、优先级、全部需求、分步实施计划、预期效果、验收条件和评审处置均在这一份文档维护。同行评审也直接审本文档，不另发一份PRD或项目计划。

当前家庭程序仍为 **r300**。P1a清单、P1b已读原件、P2日历/补录/资料及P3原作业错题/订正代表路径的软件条件已通过；家庭尚未部署这些变化。现在从原作业直接记文字或照片错题，无需先造反馈；原答、订正和帮助程度保留在同一题。当前推进P4知识点/复习及P5整体验收，真实家长体验仍未完成。具体范围、系统文件选择器/手机等未验边界和分步计划统一见[PRD.md](PRD.md)，源码通过不等于家庭升级。

- [研发规则与分工](AGENTS.md)：M4 Claude实现与内审，Codex独立验收和部署；先提交再验证，补丁再提交复验。
- [运行与发布记录](AGENT运行.md)：配置、备份、部署事实及证据，现行计划仍以PRD为准。
- [第三方许可与接入边界](THIRD_PARTY.md)：固定版本、实际复用与许可，不把部分接入称整套平台。

网页、产品Agent、采集与备份独立运行；当前以家庭局域网Mac App和同库手机网页为主。真实资料留在家庭私有目录，公开Git仅维护经审查源码和虚构示例。
