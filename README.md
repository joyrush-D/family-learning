# 一起成长 · Family Agent

把已授权学校信息和孩子补录整理成一个孩子每天清楚的课程、作业与事务，并沿原作业跟进反馈、错题、知识点和复习。

**唯一产品文档：[PRD.md](PRD.md)。** 产品目标、优先级、全部需求、分步实施计划、预期效果、验收条件和评审处置均在这一份文档维护。同行评审也直接审本文档，不另发一份PRD或项目计划。

当前家庭程序与已安装Mac App为 **r306 / build306**。周日历横跨窗口顶部；宽窗清单与详情并排，窄窗只切换日历下方内容，日期和模式始终可用，切换不移动窗口。学校事项保留完整有效要求，分清完成、交回、检查与家长安排；未采用提醒在同卡标明，并能打开它自己的原文、发布者和时间。原作业反馈、错题和批量照片继续沿原链使用。源码已同步GitHub；App静默安装、不自动打开。

口述补录是零模型手记，日期由家长选择；资料未读全或原消息时间未核实，保留具体待核。内容中重复表述仍需精简，真实家长清单与操作体验尚未验收。

照片结果分清AI判错、疑似、未判和未检查，原图、原答、教师参考与判断依据可回看；AI明确判错署名“AI判断”，未知不自动记错。同批追加照片时，能证明仍是同一原图、同题和原作答的错题保原编号与订正，新旧判断分开显示；不能定位或依据已变就明确待核，不按标题强并。原清单归并、反馈和零模型手记继续保留。

数学知识点实际复用固定知识包原引擎与DeepTutor，帮助后答对、同题订正和独立新题分别留证。真实来源覆盖、系统文件选择器和实际拖入、真实手写及普遍批改准确性、手机、另一家长、家长是否省事及教学效果仍待验；技术发布不代表整体目标完成。范围和下一步只在[PRD.md](PRD.md)维护。

- [研发规则与分工](AGENTS.md)：M4 Claude实现与内审，Codex独立验收和部署；先提交再验证，补丁再提交复验。
- [运行与发布记录](AGENT运行.md)：配置、备份、部署事实及证据，现行计划仍以PRD为准。
- [第三方许可与接入边界](THIRD_PARTY.md)：固定版本、实际复用与许可，不把部分接入称整套平台。

网页、产品Agent、采集与备份独立运行；当前以家庭局域网Mac App和同库手机网页为主。真实资料留在家庭私有目录，公开Git仅维护经审查源码和虚构示例。
