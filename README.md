## 产品怎么用

**日历是总纲：选一个孩子，按天看课程与要做的事；同一事项连接反馈、错题和学习进展。** 始终通过切换查看孩子，没有“全部”；选定一天后，事项按科目平铺。

三个入口直接可见：

- **日历**：一周浏览、直接选日、回今天；同页看课表、作业、签字/打印等事务及其完成/交回/检查时间。口头布置的作业可补录。
- **错题本**：按科目看原题、原答、错因与订正，能回原作业和原记录，继续订正后重开。
- **学习进展**：课程安排与孩子实际表现分开；看具体知识点、作答和帮助、错题订正、独立再试及证据日期，沿原记录继续诊断。不凭一次正确或上课进度宣布掌握。

最短使用路径：

1. **日历选作业 → 留反馈 → 记一道错题**；或在错题本点“记一道错题（没有原作业）”，选原照片并填科目、题目，直接保存。
2. **错题本选中那一道**：右侧看原题、原答、原图和订正；“回原作业”准确回到原事项，包含以前已办作业。
3. 数学错题点 **知识点与练习**，用日常说法查找（如“有理数加法”），选匹配知识点后开始诊断、看说明、独立再试。结果回到同一道错题与学习进展；一次做对不等于掌握。

知识点练习复用App内的原网页面板，上方“← 返回清单”或⌘+数字0回原生，所选孩子与事项保留。目前固定知识包只覆盖数学；其他科目照常记原题和订正，不虚构知识点判断。

明确学校要求由Agent理解归类，保简短标题、完整完成标准与原件；跨渠道同件事按已核关系归并，不把原文堆给家长逐条确认。题目与家长参考分别按需打印，原件、反馈和历史保留。
