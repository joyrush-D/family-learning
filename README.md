## 产品怎么用

始终选择一个孩子，所有跟踪事项按科目聚类，以平铺列表处理：**今天做什么 → 查看资料/按需打印 → 提交作答与反馈 → 留错题和订正 → 后续回看。** 老师群里没有的口头作业，可以由孩子或家长补录进同一清单。

Agent负责收集、理解与归类明确消息，只把具体疑点交给家长；发布时间、完成日、交回/检查日分别表达，老师原话和原件可追溯。孩子表现与学校要求分别保留，AI判断不等于已掌握。

## 优先级与当前边界

按[现行方案](PRD.md#1-产品目标与优先级)执行：每日待办与口头补录 → 反馈/书写/错题 → 提前准备与打印。优先交付可信每日待办；知识图谱与DeepTutor的原作业内诊断复用已进入独立开发，尚未部署。已有反馈、书写、错题及准备功能继续可用。

本次家庭局域网技术交付为 **r276：迟到的待核消息保留原本明确的完成日**。同一份活动回执当天或晚两天整理，都保留原签字完成日和次日交回日；历史待核状态、未知日期与家长明确修改保持原样，不生成当天新作业或推断孩子是否完成。900项相关测试与手机/桌面完整软件流程通过；新备份隔离恢复、原会话及配置、实际LAN双宽六原图保护通过。真实家庭准确性、手机和教育效果仍待验；知识点诊断复用尚未作为家庭能力发布。详见[现行状态](V1交付目标.md#现行状态与历史追溯)。

原错题内的数学知识点诊断（cn-math-taxonomy 固定包 + DeepTutor 判定子集）目前只是分支候选，未合入、未部署，边界见[第三方取舍](THIRD_PARTY.md)。

学校任务、作答反馈与成长分析的衔接见[方案第三节](PRD.md#3-作业如何连接孩子成长)；两个参考的复用及未接入边界见[方案第四节](PRD.md#4-两个参考怎样使用)；兴趣、阅读、健康与关系等成长范围继续保留。

## 运行与研发

当前以家庭局域网交付，网页、产品Agent、微信/QQ采集和备份由后台承担；实际采集健康以各来源回执为准。唯一主库和真实资料留私有，手动输入/文件导入可独立使用。可替换模型，公网、微信及设备接口按条件接入。
