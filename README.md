# 一起成长 · Family Agent

**把学校要求整理成清楚的每日待办，用孩子的实际作答和反馈支持成长。** 家长省事、孩子愿意参与，有原记录可核对。

## 产品怎么用

始终选择一个孩子，所有跟踪事项按科目聚类，以平铺列表处理：**今天做什么 → 查看资料/按需打印 → 提交作答与反馈 → 留错题和订正 → 后续回看。** 老师群里没有的口头作业，可以由孩子或家长补录进同一清单。

Agent负责收集、理解与归类明确消息，只把具体疑点交给家长；发布时间、完成日、交回/检查日分别表达，老师原话和原件可追溯。孩子表现与学校要求分别保留，AI判断不等于已掌握。

## 优先级与当前边界

按[现行方案](PRD.md#1-产品目标与优先级)执行：每日待办与口头补录 → 反馈/书写/错题 → 提前准备与打印。优先交付可信每日待办；原错题内的数学知识点诊断已复用 cn-math-taxonomy 与 DeepTutor 的有限子集，已有反馈、书写、错题及准备功能继续可用。

本次家庭局域网技术交付为 **r277：在原错题里诊断、帮助和新题再试**。从“今天→原作业→查看/补充反馈”的已保存错题卡进入，确认数学知识点，逐题核查、看说明，再试一道这孩子此前未见的新题；结果保留在同一作业，暂停或保存后可重开。原错题更正后，旧依据下的结果作废或待更新；单次正确不代表掌握。

两项开源代码已合入 [PR #203](https://github.com/joyrush-D/family-learning/pull/203)、[PR #204](https://github.com/joyrush-D/family-learning/pull/204)，经过独立软件验证及本轮新备份、全旧表隔离恢复、原会话与配置、LAN双宽六原图保护。数学知识包是未经教师审核的AI初稿，DeepTutor只接确定性登记/判定/作废子集，具体许可和能力边界见[第三方取舍](THIRD_PARTY.md)。真实家长准确性、手机和教育效果仍待验；每日待办仍是第一优先级，详见[现行状态](V1交付目标.md#现行状态与历史追溯)。

学校任务、作答反馈与成长分析的衔接见[方案第三节](PRD.md#3-作业如何连接孩子成长)；两个参考的复用及未接入边界见[方案第四节](PRD.md#4-两个参考怎样使用)；兴趣、阅读、健康与关系等成长范围继续保留。
