## 产品怎么用

始终选择一个孩子，所有跟踪事项按科目聚类，以平铺列表处理：**今天做什么 → 查看资料/按需打印 → 提交作答与反馈 → 留错题和订正 → 后续回看。** 老师群里没有的口头作业，可以由孩子或家长补录进同一清单。

Agent负责收集、理解与归类明确消息，只把具体疑点交给家长；发布时间、完成日、交回/检查日分别表达，老师原话和原件可追溯。孩子表现与学校要求分别保留，AI判断不等于已掌握。

## 优先级与当前边界

**当前交付目标：每日事项清楚完整，并能看见已有进展。** 学校消息、附件与口头补录进入同一孩子、同一科目的清单；直接看到做什么、何时完成、完成标准和资料。已有反馈、错题和学习进展沿原事项回看，教学和诊断复用现有开源能力。

本轮只完成这条使用路径的阻断修复、整天清单验收和家庭局域网交付。完整辅导、自动准备及长期成长需求继续保留，按后续实际需要推进；不让它们或不断增加的边界用例延长本轮。技术交付和真实家长验收分别记录，详见[完成标准](PRD.md#5-当前迭代的完成标准)。

当前迭代是“复用已有能力，把信息接成清楚的每日清单并关联进展”，以完整一天能用为交付单位。同一原事项的已保存反馈、错题和诊断/独立再试已接回清单。cn-math-taxonomy原诊断引擎和DeepTutor原LearningService已有限接入，完整教学/RAG尚未接通；上游Task Board不替换现有主库状态。其他已有功能保留，详见[方案](PRD.md)。

按[现行方案](PRD.md#1-产品目标与优先级)执行：每日待办与口头补录 → 反馈/书写/错题 → 提前准备与打印。优先交付可信每日待办；原错题内的数学知识点诊断已复用 cn-math-taxonomy 与 DeepTutor 的有限子集，已有反馈、书写、错题及准备功能继续可用。

本次家庭局域网技术交付为 **r285：原作业反馈保留科目**（[PR #226](https://github.com/joyrush-D/family-learning/pull/226)；正式登记以家庭私有回执为准）。
