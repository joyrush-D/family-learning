## 产品怎么用

始终选择一个孩子，所有跟踪事项按科目聚类，以平铺列表处理：**今天做什么 → 查看资料/按需打印 → 提交作答与反馈 → 留错题和订正 → 后续回看。** 老师群里没有的口头作业，可以由孩子或家长补录进同一清单。

Agent负责收集、理解与归类明确消息，只把具体疑点交给家长；发布时间、完成日、交回/检查日分别表达，老师原话和原件可追溯。孩子表现与学校要求分别保留，AI判断不等于已掌握。

## 优先级与当前边界

按[现行方案](PRD.md#1-产品目标与优先级)执行：每日待办与口头补录 → 反馈/书写/错题 → 提前准备与打印。优先交付可信每日待办；原错题内的数学知识点诊断已复用 cn-math-taxonomy 与 DeepTutor 的有限子集，已有反馈、书写、错题及准备功能继续可用。

本次家庭局域网技术交付为 **r281：读清原件，整理清楚任务**（[PR #212](https://github.com/joyrush-D/family-learning/pull/212)）。完整读出的图片/DOCX要求不再受固定动作词表限制；已读纯名称作为资料，真实读取缺口仍待核。保留逐项完整要求、原消息/附件归属及原候选编号，不用整段原文或逐条家长确认代替归纳。

纯文字通知初筛使用轻推理档，学校文字整理沿默认推理档；图片/视频读取、作答检查和教学继续用默认模型。本家庭在新备份与47表隔离恢复后，仅将文字轻模型升级为 `deepseek-v4-1-flash-261017`，默认模型及两档推理设置保持。M4 Claude实现，Root对精确提交独立验收：1048项方法中1041通过、7个模型反证预期失败保留，原件/设置的360/1440流程、5份实际原件文字回执的精确请求重放、4条普通文字实际调用及六消息归纳的独立语义回放通过。这些有限样例不证明OCR或普遍准确率。

代码切换另取新停写一致备份，隔离恢复47旧表，原41家长会话含到期日、15份当时配置、七服务及261文件模式保留；实际LAN匿名双宽完整页与六原图在原30秒内通过，正式登记以家庭私有回执为准。原日期显示、PDF完整要求和两个开源引擎的有限数学诊断继续保留。已耗尽批次不自动加次数，已保存历史不批量重写；来源/原件覆盖、旧HTTP附件sha256断言、真实家长/手机和教育效果继续验。许可和边界见[第三方取舍](THIRD_PARTY.md)。

下一家庭版本的两项增量已完成独立软件验收：

- 同老师明确回指的补充与部分免除，保留最终有效的执行者、步骤、数量、范围及原话；只免家长签名时，孩子签名仍保留。含已证明绑定更正的请求仍用文字轻模型，沿已配置默认推理档；普通初筛、调用、超时、输出和重试上限不变。
- 完成、交回、检查与课堂安排分别读清：“今晚跟读，明天上课检查”保留今晚完成和明日检查；“今晚勾选并签名，下周一交回”保留两种日期；单纯课堂活动是安排日，“今晚不用交”不产生今晚截止，携带用品也不因“无需居家练习”变成家庭作业。

Root以13条冻结虚构日期/分类案例、两份既有实际模型回执的原样请求和保存重开、360/1440清单及原流程复验；模型回放未新增调用。已有原话、原件、反馈及历史不批量重写，不完整或矛盾的摘要仍待核。**家庭仍为 r281**，保护发布尚未执行；这些有限软件证据不证明全面归纳准确、真实手机或教育效果。
