# 一起成长 · Family Agent

把已授权学校信息和孩子补录整理成一个孩子每天清楚的课程、作业与事务，并沿原作业跟进反馈、错题、知识点和复习。

**唯一产品文档：[PRD.md](PRD.md)。** 产品目标、优先级、全部需求、分步实施计划、预期效果、验收条件和评审处置均在这一份文档维护。同行评审也直接审本文档，不另发一份PRD或项目计划。

当前家庭程序与已安装Mac App为 **r303 / build303**，已完成本轮清单归并、原生界面和原作业反馈链的软件验收及受保护技术发布。打开App，选一个孩子和日期，从同一作业继续看资料、留作答或记错题，再回同一道题看订正、知识点与复习安排。源码已同步GitHub；App不会由研发自动打开。

针对家长反馈的体育重复与界面难读，r303让同一事项的多次提醒沿原后台归并，原来源、附件和旧反馈仍可查；原生清单完整显示要求，较窄窗口点开详情后可返回原孩子、日期和选择，宽窗口并排查看。这次已核对代表场景、保存重开和失败重试；真实清单仍待家长复验，不能据此宣称全科目准确或整体目标完成。一批照片自动分科、组卷和找错仍在独立开发验收，未包含在本版。

数学知识点实际复用固定知识包原引擎与DeepTutor，帮助后答对、同题订正和独立新题分别留证。真实来源覆盖、系统文件选择器、手机、另一家长、家长是否省事及教学效果仍待验；技术发布不代表整体目标完成。范围和下一步只在[PRD.md](PRD.md)维护。

- [研发规则与分工](AGENTS.md)：M4 Claude实现与内审，Codex独立验收和部署；先提交再验证，补丁再提交复验。
- [运行与发布记录](AGENT运行.md)：配置、备份、部署事实及证据，现行计划仍以PRD为准。
- [第三方许可与接入边界](THIRD_PARTY.md)：固定版本、实际复用与许可，不把部分接入称整套平台。

网页、产品Agent、采集与备份独立运行；当前以家庭局域网Mac App和同库手机网页为主。真实资料留在家庭私有目录，公开Git仅维护经审查源码和虚构示例。
