**把学校要求整理成清楚的每日待办，用孩子的实际作答和反馈支持成长。** 家长省事、孩子愿意参与，有原记录可核对。

## 产品怎么用

始终选择一个孩子，以简洁列表处理：**今天做什么 → 查看资料/按需打印 → 提交作答与反馈 → 留错题和订正 → 后续回看。** 老师群里没有的口头作业，可以由孩子或家长补录进同一清单。

Agent负责收集、理解与归类明确消息，只把具体疑点交给家长；发布时间、完成日、交回/检查日分别表达，老师原话和原件可追溯。孩子表现与学校要求分别保留，AI判断不等于已掌握。

## 优先级与当前边界

1. 每日待办完整、清楚、分类正确，口头补录顺手。
2. 作业反馈、书写规范、错题、订正和独立复测。
3. 提前准备、打印、预审和参考讲解。

家庭正式元数据当前为 **r271**；公开源码与家庭部署分别登记，整体目标尚未完成。局域网页面、后台整理、手记、反馈、错题/订正和打印队列已有软件基础；来源/原件覆盖、稳定归纳与批改质量、真实手机和家长体验、实际出纸与教育效果继续验收。

知识点拟复用cn-math-taxonomy；交互资料参考WeduLab，按许可评估edulab生成器。三者均未接入家庭版，不以方案或开源源码替代实测。兴趣、阅读、健康与关系等成长范围继续保留。

## 运行与研发

当前以家庭局域网交付，网页、产品Agent、微信/QQ采集和备份由后台承担；实际采集健康以各来源回执为准。唯一主库和真实资料留私有，手动输入/文件导入可独立使用。可替换模型，公网、微信及设备接口按条件接入。

GitHub `main` 是唯一公开长期主线；M4 Claude实现，本机Codex验收与部署。先提交、再验证，补丁再提交复验；不将源码合入、技术发布或测试通过写成家长满意。开发会话不接管日常业务。
